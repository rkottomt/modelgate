    Run model code before you trust it

    Loading a Hugging Face model with trust_remote_code=True runs Python from the repo on your machine, before you call the model. On 29 October 2026, Pluto Security reported 31 repos across seven accounts, with more than 32,000 downloads, that used exactly this to install a crypto miner and a backdoor. Hugging Face's antivirus and partner scanners didn't flag them.

    ModelGate runs that code first, in an offline container that looks like a GPU server with decoy keys, and records everything it does: the kernel sees every connection and process, and Python names the line that caused it. About three seconds per repo.

    Try : its payload only fires inside forward() on a GPU, so reading the code or just importing it misses it.
