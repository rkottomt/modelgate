    Check custom model code before it runs

    Loading a model with trust_remote_code=True runs Python from the repo on your machine. ModelGate downloads that code (never the weights), reads it, runs it in a locked-down container, and tells you whether it's safe to load.

    Allow
    No risky behaviour found. Load it pinned to the scanned commit.
    Warn
    Something needs a human look, e.g. a network library or a reference to another repo.
    Block
    The code tried something a model has no reason to do: opened a socket, read your keys, spawned a shell.

    Verdicts come from fixed rules only. The AI write-up explains them and can't change them. Press / to jump to the search box.

    Scanning
    1. Resolve the revision to a commit and download code files
    2. Read the code for risky calls and hidden instructions
    3. Run it in an offline container and record what it does
    4. Apply the rules
