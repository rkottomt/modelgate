ModelGate

Loading an AI model can run its author's code on your machine.
ModelGate checks that code first.

github.com/rkottomt/modelgate

One flag runs a stranger's code.

model = AutoModel.from_pretrained("org/model", trust_remote_code=True)

It runs firstThe repo's Python runs on import, with your keys, tokens and network, before you call the model.
