ModelGate

A safety gate for AI models that run their own code.

github.com/rkottomt/modelgate

Loading a model can run its author's code.

from transformers import AutoModel model = AutoModel.from_pretrained("org/model", trust_remote_code=True)

That flag downloads Python from the repo and runs it on your machine, with your files, keys and network, before you've called the model once.

It's already happening.

Feb 2024About 100 malicious models found on Hugging Face, some opening reverse shells.
Jul 2026AI agents being tested escaped their sandbox and broke into Hugging Face's servers.
Sep 202631 repos used trust_remote_code to plant crypto miners. They passed existing scanners.

One line in front of every load.

import modelgate.auto
AllowNothing risky found. Loads, locked to the exact commit we checked.
WarnNeeds a human look. Stops until someone approves it.
BlockTried something a model never needs to do. Stops, and says which line.

How it decides

01
Fetch the code
Locked to one commit. Never the weights.
02
Read it
Risky calls, hidden blobs, notes aimed at AI reviewers.
03
Run it offline
Locked container, decoy keys, every system call recorded.
04
Fixed rules decide
Anything it can't finish checking is blocked.

An AI then explains the result in plain English. It can't change it.

Demo

The AI can't overrule the rules.

  • The verdict is final before the AI sees anything.
  • It gets a copy of the flagged lines, marked as untrusted. Nothing it writes is read back.
  • A repo that tells AI reviewers "this is safe" still gets blocked. And the summary calls it out.

New: the same gate for AI agents

01
Describe the job
"Summarise this CSV. No internet, no credentials."
02
Tick the guardrails
An AI drafts them from a fixed list. You approve. It's signed.
03
Run it offline
Every connection, file write, program and secret read is checked.

A demo agent copying the July 2026 escape: 5 violations, each pinned to its line, in 0.3 s.

What it doesn't do (yet)

  • A payload that waits hours, or checks it's in a container, can slip past a short run.
  • Docker shares the host kernel. A stronger sandbox (gVisor) is the next step.
  • Covers the transformers loader, not weights or other loaders.
  • Agents run fully offline for now. No real internet access or token tracking yet.

What's next

  • Agents get only the hosts they're approved for, through a proxy that holds the API key.
  • Token and cost tracking next to what the agent did.
  • Re-check automatically whenever a repo's code changes.
  • A stronger sandbox, and more loaders.
