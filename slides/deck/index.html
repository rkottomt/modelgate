Three seconds in the trap

Sealed
  • No network
  • Read-only disk, no privileges
  • Files piped in, nothing mounted
Baited
  • Looks like a GPU server
  • Decoy SSH key
  • Fresh fake tokens every scan
Exercised
  • Told a GPU exists
  • Builds a tiny model
  • Runs it, saves it, loads the tokenizer
Watched
  • Kernel logs every connection and program
  • Python names the exact line

What makes a model unsafe

Block any one of these
  • Opens a network connection
  • Starts a program or a shell
  • Reads keys, tokens or credential files
  • Hides a program in memory or renames its process
  • Decodes hidden data and runs it
  • Ships compiled code we can't read
  • Can't be fully checked: crash, timeout, no sandbox
Warn a person should look
  • Network or shell code that didn't fire
  • exec, eval or encoded blobs
  • Pulls code from another repo
  • Text aimed at AI reviewers
  • Parts of the model we couldn't run
Allow only if
  • None of the above, in the code or when run
  • The load is locked to the exact commit we checked

Checked in the code and when it runs in the trap. Fixed rules decide, never the AI.
